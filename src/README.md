# 💻 Código Fuente

Esta carpeta reúne la implementación modular del framework metodológico.

Su objetivo es transformar el notebook en una estructura reutilizable, organizada y fácilmente mantenible.

---

# Contenido

Los módulos incluyen funciones relacionadas con:

- Simulación del sistema.
- Preparación de datos.
- Análisis Exploratorio de Datos.
- Construcción de modelos.
- Evaluación del desempeño.
- Interpretabilidad.
- Visualización de resultados.

---

# Objetivo

Facilitar la reutilización del framework en nuevos casos de estudio pertenecientes a distintos dominios de aplicación.

---

> "Un buen notebook demuestra una solución; un buen código permite reutilizarla."
