# 📓 Notebook Principal

Esta carpeta contiene el notebook desarrollado durante la investigación.

El notebook constituye el núcleo técnico del proyecto y documenta, paso a paso, el proceso metodológico seguido para responder la pregunta de investigación.

---

# Contenido

## 📘 Estadistica_vs_Machine_Learning.ipynb

Incluye:

- Diseño conceptual del problema.
- Construcción del Motor de Simulación.
- Generación de datasets.
- Análisis Exploratorio de Datos (EDA).
- Entrenamiento de modelos predictivos.
- Evaluación del desempeño.
- Interpretabilidad.
- Lecciones metodológicas.

---

# Objetivo

Más que enseñar algoritmos, este notebook busca demostrar que la selección de un modelo predictivo debe estar determinada por la complejidad del fenómeno y no únicamente por la disponibilidad de herramientas computacionales.

---

> "Antes de elegir un algoritmo, debemos comprender el fenómeno."
