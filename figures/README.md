# 📈 Figuras

Esta carpeta reúne las principales figuras utilizadas durante el desarrollo del proyecto.

Las imágenes complementan el notebook y la documentación técnica, facilitando la comunicación visual de los resultados.

---

# Contenido

Incluye, entre otras:

- Distribución del rendimiento.
- Matriz de correlación.
- Variables explicativas.
- Comparación entre valores reales y predichos.
- Importancia de variables.
- Diagramas metodológicos.

---

# Objetivo

Favorecer la interpretación visual de la metodología y de los resultados obtenidos.

---

> "Una buena visualización no reemplaza el análisis; lo hace más comprensible."
