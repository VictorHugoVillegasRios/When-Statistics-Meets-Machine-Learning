
# 📊 Conjuntos de Datos

Esta carpeta contiene los conjuntos de datos utilizados durante el desarrollo del framework metodológico.

Los datasets fueron construidos mediante simulación con el propósito de representar fenómenos con niveles crecientes de complejidad, permitiendo analizar el momento en que la Estadística Tradicional deja de ser suficiente y el Machine Learning comienza a aportar un valor significativo.

---

# Contenido

## 📁 exp1.csv

Sistema con relaciones predominantemente lineales.

Objetivo:

Evaluar el desempeño de la Regresión Lineal en un escenario de baja complejidad.

---

## 📁 exp2.csv

Sistema con múltiples variables y relaciones lineales.

Objetivo:

Analizar el efecto de incorporar nuevos factores explicativos manteniendo un comportamiento estadístico tradicional.

---

## 📁 exp3.csv

Sistema con interacciones crecientes entre variables.

Objetivo:

Observar el punto de transición donde comienzan a aparecer ventajas del Machine Learning.

---

## 📁 exp4.csv

Sistema con relaciones no lineales e interacciones complejas.

Objetivo:

Representar un fenómeno cuya complejidad requiere modelos predictivos más avanzados.

---

# Importante

Estos datasets fueron diseñados con fines metodológicos y educativos.

No representan información observacional de un sistema real, sino escenarios simulados que permiten estudiar el comportamiento de distintos modelos predictivos.

---

> "La calidad del modelo depende, en gran medida, de la calidad con la que representamos el fenómeno."
