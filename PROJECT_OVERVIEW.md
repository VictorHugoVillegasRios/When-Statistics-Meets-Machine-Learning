# PROJECT OVERVIEW

# ¿Cuándo la Estadística deja de ser suficiente y comienza el Machine Learning?

## Framework metodológico para seleccionar modelos predictivos en función de la complejidad del fenómeno

---

## Resumen

La selección entre métodos estadísticos tradicionales y algoritmos de Machine Learning constituye una de las decisiones metodológicas más importantes en Ciencia de Datos.

Sin embargo, esta decisión suele tomarse comparando algoritmos o métricas de desempeño, sin considerar adecuadamente la naturaleza del fenómeno que se desea modelar.

Este proyecto propone un enfoque diferente.

En lugar de preguntar **qué algoritmo obtiene mejores resultados**, plantea una pregunta previa y fundamental:

> **¿Cuándo la complejidad del fenómeno hace necesario utilizar Machine Learning?**

Para responder esta pregunta se diseñó un framework metodológico validado mediante un caso de estudio basado en experimentos con complejidad creciente.

---

# El problema

Con frecuencia, los proyectos de Ciencia de Datos comienzan directamente con la comparación entre algoritmos predictivos.

Este enfoque puede conducir a seleccionar modelos innecesariamente complejos para problemas que todavía pueden resolverse adecuadamente mediante métodos estadísticos tradicionales.

El presente framework propone invertir este proceso.

Primero comprender el fenómeno.

Después seleccionar el modelo.

---

# La propuesta

El framework desarrollado sigue siete etapas:

1. Comprensión del fenómeno.
2. Modelo conceptual.
3. Simulación del sistema.
4. Análisis Exploratorio de Datos.
5. Construcción de modelos predictivos.
6. Interpretabilidad.
7. Lecciones metodológicas.

Este enfoque puede aplicarse a diferentes dominios del conocimiento, más allá del caso de estudio utilizado durante la investigación.

---

# Principales resultados

El desarrollo de cuatro experimentos con complejidad creciente permitió demostrar que:

- La Regresión Lineal mantiene un excelente desempeño cuando predominan relaciones simples entre variables.
- A medida que aumenta la complejidad del sistema, los modelos de Machine Learning comienzan a capturar relaciones que los modelos lineales no representan adecuadamente.
- La selección del modelo debe depender de la complejidad del fenómeno y no únicamente de la disponibilidad de algoritmos.

---
